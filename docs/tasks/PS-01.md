# PS-01 — Preflight do run e encerramento do filho

Status: planejada.

Base: `wip/dx-08a1-review-2`.

## Objetivo único

Validar uma vez, antes do spawn, que o run directory não é symlink, pertence ao
usuário e tem modo `0700`; qualquer erro posterior de status ou heartbeat deve
terminar e coletar o grupo supervisionado.

## Escopo

- reutilizar os helpers existentes, sem criar nova camada de persistência;
- falhar antes do spawn para diretório inválido;
- em erro posterior, executar cleanup e `wait()` do filho;
- alterar somente runtime, state machine, helper estritamente necessário,
  testes focados e documentação desta task;
- registrar que processos com o mesmo UID são confiáveis.

Não perseguir trocas deliberadas de componentes/inodes pelo mesmo UID, migration,
rollback, reports ou outros fluxos.

## Aceite

- diretório válido mantém o comportamento atual;
- symlink direto, owner incorreto e modo diferente de `0700` falham antes do spawn;
- erro injetado após spawn não deixa processo vivo;
- nenhuma operação Git ou de rede é adicionada;
- suíte completa e checks estáticos passam.
