# DX-08A1 — Relatório Cursor seguro na extensão de iterações

Status: planejada.

Base obrigatória: `wip/dx-08a-review-7`.

Próxima task: [DX-08A2](DX-08A2.md).

## Contexto

O review 7 da DX-08A reproduziu uma extensão de orçamento usando
`cursor-<iteration>.json` com conteúdo `not json` e modo `0644`.
`_authorize_iteration_extension_locked()` verifica apenas tipo e tamanho do
arquivo antes de promover o evento crítico.

## Objetivo único

Fazer a autorização de iterações aceitar somente um relatório Cursor Agent
privado, lido sem seguir links e válido segundo o envelope de produção já
usado por `snapshot.py`.

## Escopo obrigatório

1. Substituir a validação superficial de `cursor-<iteration>.json` em
   `_authorize_iteration_extension_locked()` pela API segura comum.
2. Reutilizar ou extrair o validador existente do envelope Cursor Agent; não
   criar um segundo contrato divergente.
3. Recusar antes de qualquer mutação:
   - JSON ausente, vazio, truncado ou malformado;
   - schema/contrato futuro ou campos ausentes, extras ou de tipo inválido;
   - symlink, hard link, arquivo não regular ou troca de inode;
   - modo diferente de `0600` e owner inesperado.
4. Preservar a autorização normal com um envelope real de
   `cursor --output-format json`.
5. Ajustar `ROADMAP.md` e esta task apenas com a garantia específica provada;
   DX-08 e M1 continuam abertos.

## Limite de mudança

Arquivos de produção permitidos:

- `scripts/agents/dx/runstate.py`;
- `scripts/agents/dx/snapshot.py`, somente para compartilhar o contrato.

Testes em `tests/unit/test_agent_dx08a.py` e documentação citada acima.
Não alterar runtime, locks, transactions, migration, rollback ou outros fluxos
de reports. Não fazer refatorações adjacentes.

## Critérios de aceite

1. Todos os relatórios inseguros listados são recusados.
2. Na recusa, budget, status, audit, journal e diretório permanecem
   byte-a-byte inalterados.
3. Um envelope de produção válido ainda autoriza a extensão.
4. A suíte completa e as validações estáticas passam.

## Testes obrigatórios

- tabela parametrizada para malformed, future/unknown fields, symlink,
  hard link, owner, `0644`, `0666` e arquivo vazio;
- envelope real válido;
- snapshot do diretório e dos artefatos críticos antes/depois de cada recusa;
- `pytest tests/unit`;
- `python3 -m compileall -q scripts/agents/dx`;
- `bash -n` nos scripts shell;
- `git diff --check`.
