# PC-01B1 — Unificar metadata e status

Status: em implementação.

## Objetivo

Substituir `run.json` e `status` por um único `state.json` atômico.

## Aceite

- `state.json` contém schema, run id, metadata congelada e status;
- transições preservam metadata sob `.state.lock`;
- inicialização preserva `RUN_STARTED` já publicado;
- leitura recusa symlink, arquivo grande, JSON inválido e binding de run errado;
- publicação usa fsync do arquivo e do diretório;
- não existe fallback de leitura para `run.json` ou `status`;
- resume e gate existentes continuam funcionando;
- suíte completa passa.

Failure, decisão e orçamento permanecem temporariamente separados até PC-01B2.
