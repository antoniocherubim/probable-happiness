# PS-04 — Segredos separados por fase

Status: planejada.

Depende de: [PS-03](PS-03.md).

## Objetivo único

Fazer bootstrap, executor e validações receberem allowlists de ambiente distintas.

## Escopo

- listas `bootstrap_required`, `executor_required` e `validation_required`;
- construir ambiente novo por subprocesso;
- reviewer não recebe segredos do projeto;
- valores nunca entram em state, heartbeat, diagnóstico ou documentação;
- formato legado tem comportamento conservador documentado;
- sem cofre, streaming Git ou cleanup.

## Aceite

- cada fase recebe somente os nomes declarados para ela;
- variável reservada ou configuração ambígua é recusada;
- logs e diagnóstico mostram somente `NOME=set|unset`;
- testes usam canários e provam ausência nas fases indevidas;
- suíte completa e checks estáticos passam.
